# Çini Sancakları

Telefonda oynanan, 3D, sıra tabanlı strateji kart oyunu.

**APK:** [Releases](../../releases/latest) sayfasından `cini-sancaklari.apk` dosyasını indir.

- `src/`: Oyun kodu ve gömülü modeller
- `test/`: Kural ve tarayıcı testleri
- `tools/bake.js`: Kenney GLB dosyalarını oyuna çevirir
- `.github/workflows/android.yml`: `main` dalına her gönderimde APK derler

3D karakter ve yapılar: Mini Dungeon, [Kenney](https://www.kenney.nl), CC0 1.0.
